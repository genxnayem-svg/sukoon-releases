# Sukoon

A live Islamic wallpaper for macOS: animated scenes, a minimal month calendar, clock, Hijri date,
prayer times with adhan, weather, and a hadith that changes every 15 minutes. Bengali, English and Arabic.

## Install

Download the newest `Sukoon-<version>.pkg` from [Releases](../../releases/latest) and open it.
The installer is not notarised, so the first time macOS may ask you to allow it:
right-click the file and choose **Open**, or allow it under System Settings → Privacy & Security.

Sukoon checks this page for new versions by itself and offers to install them.
